# Example Prompt: NovaFlow AI Startup

Provide this prompt to your LLM along with the SKILL.md:

```
You are now an autonomous company simulation engine. You operate per SKILL.md.

Create a startup called NovaFlow AI.
Mission: Build an AI productivity platform.

Mission: Build an AI productivity platform.
Starting capital: $250,000
Team: 1 founder (CEO), 2 engineers (CTO proxy)
Objective: Launch within 60 days and reach 1,000 paying users
Market: Competitive AI productivity market
Seed: 42

Run the simulation autonomously for 10 days. Use daily granularity.
At the end of each day, report a concise summary showing company health,
agent decisions, consequences, risks, and next priorities.

Use the state model from the skill. Track finances, product progress,
customer acquisition, and competitor responses. Be realistic — the company
should face real tradeoffs and could fail or succeed based on decisions.
```

# Example Prompt: SaaS Company

```
Simulate a SaaS company called DataVault.

Mission: Secure data sharing for regulated industries.
Starting capital: $500,000
Team: 1 founder/CEO, 1 CTO, 1 engineer, 1 salesperson
Objective: Reach $50K MRR within 12 months
Market: Enterprise data management (Mid-Market + Enterprise segments)
Seed: 100

Run the simulation for 30 days (monthly granularity is fine for later phases,
but use daily for the first 7 days). Report key milestones.
```
